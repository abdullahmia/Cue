Easy Step-by-Step Installation

Choose your preferred install method below. No external Python dependencies (pip) required: only Zsh (5.x+) and Python 3.

1

Run the installer

Clones into ~/.local/share/cue, adds cue to PATH, and hooks into ~/.zshrc.

bash / zsh 
curl -fsSL https://raw.githubusercontent.com/abdullahmia/Cue/main/install.sh | bash
2

Reload your shell

Applies the ZLE keybindings & hooks right away (or open a new terminal tab).

zsh 
source ~/.zshrc
3

Complete quick onboarding

Starts immediately with zero API key needed (Recents & History active). Enable optional AI with OpenRouter :free, ChatGPT, Gemini, Claude, Groq, DeepSeek, or Ollama via:

cli 
cue settings
1

Tap & install via Homebrew

Installs directly from the single abdullahmia/Cue repository formula.

homebrew 
brew tap abdullahmia/cue https://github.com/abdullahmia/Cue.git
brew install abdullahmia/cue/cue-zsh
2

Enable in ~/.zshrc

Zsh plugins must be sourced in ~/.zshrc so line-editor widgets bind cleanly.

zsh 
echo 'source "$(brew --prefix)/opt/cue-zsh/share/cue-zsh/cue.plugin.zsh"' >> ~/.zshrc
source ~/.zshrc
3

Update or verify anytime

Upgrade seamlessly with Homebrew whenever new releases ship.

upgrade 
brew update && brew upgrade cue-zsh

Oh My Zsh

Clone into custom plugins, then add cue to plugins=(...):

zsh 
git clone https://github.com/abdullahmia/Cue.git "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/cue"

Zinit

Add this line inside your ~/.zshrc:

~/.zshrc 
zinit light abdullahmia/Cue

Sheldon

Add to ~/.config/sheldon/plugins.toml:

plugins.toml 
[plugins.cue]
github = "abdullahmia/Cue"

Windows PowerShell (5.1 & pwsh)

Adds cue.ps1 to your PowerShell $PROFILE:

powershell 
git clone https://github.com/abdullahmia/Cue.git $HOME\cue
cd $HOME\cue
.\install.ps1

Bash (macOS / Linux / Git Bash)

Source the Bash adapter in ~/.bashrc:

bash 
source ~/.local/share/cue/bash/cue.bash
